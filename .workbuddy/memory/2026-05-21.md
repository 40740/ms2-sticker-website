## 修复 Header 与面包屑导航重叠问题

### 问题
- `/materials`, `/industries`, `/pages/blank-labels` 等页面顶部邮箱和面包屑导航与 fixed header 重叠
- 原因：这些页面未传入 `transparentOnTop` 参数（默认 true），导致 header 透明且内容无 padding-top

### 解决方案

- materials/index.blade.php
- materials/show.blade.php
- industries/index.blade.php
- industries/show.blade.php
- pages/blank-labels.blade.php
- pages/show.blade.php
- shapes/index.blade.php
- shapes/show.blade.php
- products/catalog.blade.php
- products/show.blade.php

首页 (home.blade.php) 保留 `transparentOnTop => true`，因为它使用 Hero Carousel 需要透明效果。

### 效果
- Header 始终显示为白色背景
- 内容区域自动添加 padding-top 避免被 header 遮挡
- 邮箱、电话等联系信息始终清晰可见

## 修复后台登录 Bcrypt 哈希错误

### 问题
- 后台登录报错：`This password does not use the Bcrypt algorithm.`
- 即使更新 PHP 版本仍无法登录

### 根本原因
- 数据库中的密码哈希不是有效的 Bcrypt 格式
- 哈希值 `$2b$10$tE3YR9LMaPkeSWxsxRoas.6lftmq/...` Salt 部分只有 21 字符（应该是 22）
- `password_get_info()` 返回 `algoName: unknown`
- 原因：之前某次操作导致哈希被截断

### 解决方案
1. 用 PHP `password_hash()` 重新生成完整的 Bcrypt 哈希
2. 验证 `password_get_info()` 返回 `algoName: bcrypt`
3. 验证 `password_verify()` 能正确验证密码
4. 更新数据库 users 表

### 登录凭据
- 邮箱: `admin@meisaiprinting.com`
- 密码: `admin123`

### 预防措施
- 修改哈希时确保完整保存 60 字符
- 使用 PHP 直接生成哈希，不要通过 Python 或其他工具转换
